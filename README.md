# Josefine Peterson – CV & Portfolio

Personlig CV- och portfoliowebbplats byggd med HTML, CSS och JavaScript – inga byggsteg behövs.

## Struktur

```
├── index.html       # CV
├── portfolio.html   # Portfolio med fem projekt
├── style.css        # All styling (ljust/mörkt tema)
├── js/main.js       # CV-data, tema, mobilmeny, scroll-animationer, bildvisare
└── images/          # Porträtt och projektbilder
```

## Öppna lokalt

Öppna `index.html` i valfri webbläsare.

## Features

- CV med utbildning, färdigheter, erfarenhet och intressen
- Portfolio med Problem / Mål / Process / Resultat per projekt
- Klicka på en projektbild för att förstora den
- Ljust och mörkt tema som sparas i webbläsaren
- Responsiv layout för mobil, surfplatta och desktop
